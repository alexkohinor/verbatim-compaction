# verbatim-compaction: выводы из разбора Lightfield

**Дата:** 25.09.2026 · **Статус:** неприменимо.

Файл лежит в `docs/` и в npm-пакет не попадает: `package.json` публикует только `dist`, `README.md`,
`LICENSE`, `NOTICE`.

## Что это за репозиторий

Плагин Claude Code и npm-библиотека. Сжимает сессию, удаляя устаревший вывод инструментов вместо
пересказа. Работает по правилам, без модели и без сети.

## Что такое Lightfield

Американская CRM с ИИ (lightfield.app), раунд A на $47 млн от a16z в сентябре 2026. Карточка клиента
заполняется сама из разговоров. Главная жалоба пользователей — ИИ сам пишет в систему неверные
записи.

## Вывод

Неприменимо. Приёмы Lightfield — самозаполнение карточек, история полей, бриф, MCP, модель цены —
относятся к CRM. У библиотеки нет ни данных клиентов, ни ИИ-вызовов.

Параллель есть только на уровне принципа, и он уже соблюдён: библиотека не доверяет модели решение
о том, что удалить, и никогда не удаляет запись о том, что изменило мир (README, раздел «The rules»).
Это тот же принцип, что «решает детерминированный код, а не модель». Менять ничего не нужно.
